# 🏥 Healthcare Data Analysis Dashboard | Excel

## 📌 Project Overview

This project is an interactive **Healthcare Data Analysis Dashboard developed using Microsoft Excel**.

The objective of the project is to consolidate healthcare-related customer data, calculate important medical and financial KPIs, and present the results through an easy-to-understand dashboard.

The analysis covers customer demographics, BMI, diabetes-related measurements, smoking status, cancer history, hospitalization information, surgeries, and healthcare charges.

---

## 🎯 Project Objectives

- Consolidate healthcare data from multiple datasets
- Perform data lookup and transformation using Excel formulas
- Calculate healthcare KPIs
- Analyze customer health characteristics
- Understand healthcare cost distribution
- Build an interactive Excel dashboard
- Present healthcare information in a simple visual format

## 📈 Dashboard Analysis

The dashboard includes analysis of:

### 🚬 Customer Distribution by Smoking Status
Customer records are grouped according to smoking status to understand the distribution of smokers and non-smokers in the dataset.

### 🎗️ Cancer History Analysis
The dashboard compares customers based on whether they have a recorded history of cancer.

### ⚖️ Healthcare Charges by Weight Status
Healthcare expenditure is analyzed across different weight categories such as:

- Normal Weight
- Overweight
- Underweight
- Obesity

This helps identify how healthcare costs are distributed among different BMI/weight groups.

### 🩺 Medical Metrics
Additional healthcare indicators analyzed include:

- BMI
- HBA1C
- Age
- Number of major surgeries
- Hospitalization
- Healthcare charges

---

## 🔎 Interactive Filters

The dashboard contains filters that allow users to analyze the data based on selected healthcare attributes, including:

- Weight Status
- Diabetes Status

These filters make it easier to explore specific groups within the healthcare dataset.

---

## 🔄 Data Preparation

Healthcare information was consolidated into an analysis-ready dataset using Excel lookup operations.

`XLOOKUP` was used to retrieve related customer, medical examination, and hospitalization information using customer IDs.

The prepared dataset was then used to calculate healthcare metrics and create the dashboard visualizations.

## 📂 Workbook Structure

The Excel workbook contains dedicated sections for:

- **Healthcare Dataset** – Consolidated healthcare records
- **Medical Metrics** – Calculated healthcare KPIs
- **Healthcare Dashboard** – Interactive visual dashboard
- **Dashboard Analysis Data** – Supporting data used for dashboard analysis
